# ZippedIn Game

A clean, grid-based logic puzzle built for Android.

Connect numbered cells in order using one continuous path while filling the entire grid. Inspired by the LinkedIn ZIP daily puzzle and implemented fully in native Android (Java).

---

## Features

* Procedural puzzle generation
* Custom Canvas rendering engine
* Smooth touch path drawing
* Win detection system
* Responsive grid scaling for all devices
* Lightweight and fast

---

## Tech Stack

* **Language:** Java
* **Platform:** Android
* **Rendering:** Canvas API
* **Architecture:** Custom game logic engine
* **IDE:** Android Studio
